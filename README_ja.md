# Mieie 見える図面 ― 配布ツール(最小版)

図面PDFを**配布先ごとの個別リンク**で渡し、**誰がいつ開いたか**を記録し、**失効**させられる。
1日分の閲覧ログを書き出して、既存の刻印ツールでチェーンへ刻む。

2026-09-18 作成。Hackathon Canvasの「最初に作るもの」1〜4番をそのまま形にしたもの。

---

## 外部依存

**なし。** Python 3 の標準ライブラリだけで動きます(Mac標準のpython3で可)。
外部公開には `ssh`(Mac標準)を使います。追加インストールは不要です。

---

## 起動手順

### 1. 起動する

`起動する.command` をダブルクリック。
(初回だけ「開発元を確認できない」と出たら、右クリック →「開く」)

ターミナルに管理画面のアドレスが表示されます。

```
管理画面(このMacから):  http://localhost:8787/admin/XXXXXXXX
```

**この `/admin/XXXXXXXX` の部分が管理キーです。**他人に教えないでください。
`config.json` に保存されているので、毎回同じです。

### 2. 外部に公開する(相手に見せるとき)

`公開する.command` をダブルクリック。別のターミナルが開き、

```
https://xxxx-xxxx.lhr.life
```

のような公開アドレスが表示されます。**これが配布先に届くアドレスの土台**です。

管理画面を公開アドレスで開き直します:`https://xxxx-xxxx.lhr.life/admin/XXXXXXXX`

> ⚠️ **公開アドレスは、公開を止めるたびに変わります。**
> 相手に送るリンクは、公開した後に管理画面(公開アドレス側)で発行してください。
> 公開を止めると、送ったリンクは開けなくなります。試験の間は公開したままにしてください。

### 3. 図面を登録し、リンクを発行する

管理画面で:

1. **図面を登録する** ― 物件名・図面名・PDF
2. **配布先にリンクを発行する** ― 図面を選び、相手の名前(例:オリオン様)を入れる
3. 発行されたリンクを、メール・LINE等で相手に送る

相手は**リンクを開くだけ**です。登録・アプリ・ウォレットは不要。
図面の上に「〇〇様用 / 閲覧 日時」が薄く重なります(スクリーンショットにも残る)。

### 4. 閲覧状況を見る・失効させる

管理画面の「3. 配布先と閲覧状況」に、誰が何回・いつ開いたかが出ます。
「失効させる」を押すと、そのリンクは即座に開けなくなります。

### 5. 閲覧ログを刻印する(1日1回)

管理画面の「5. 1日分の閲覧ログを書き出す」で日付を選んで書き出す。2つのファイルができます。

| ファイル | 中身 | 刻印 |
|---|---|---|
| `刻印用_閲覧ログ_YYYY-MM-DD.json` | ランダムな配布先ID・時刻・図面のハッシュ・ソルトだけ | **これを刻印する** |
| `閲覧ログ_YYYY-MM-DD_控え.json` | 配布先の名前・IP・端末を含む完全な記録 | **刻印しない**(手元保管) |

**なぜ分けるか(個人情報保護法への備え):** 名前入りのログのハッシュをチェーンに刻むと、
元のログが残る限り「個人データ」とみなされうる。チェーンは消せないので、削除請求と衝突する。
刻印用に名前を入れず、手元の対応表(`data/mieie.db`)だけで名前と結びつける形にしておけば、
対応表を消した時点でチェーン上のハッシュは誰とも結びつかなくなる。
(2026-09-23、Colosseum Copilot の検証結果を受けて変更)

`刻印用_…json` を **刻印ツール(`書類/見える家_NFTプロトタイプ/mieie_nft_tool.html`)** の
「② 記録をNFT化する」に入れて刻印する。

- 物件名:`閲覧ログ`
- 記録種別:`配布ログ YYYY-MM-DD`

これで「その日の閲覧記録が、後から書き換えられていない」ことを誰でも検証できます。
**鍵(MetaMask)を扱う操作は、ツールではなく人間が行います。**

### 終了

各ターミナルで **Control + C**。

## 何が分かって、何が分からないか

| | 分かる | 分からない |
|---|---|---|
| 配布先が開いたか | ○ 日時・回数 | ― |
| 別の人に転送されたか | ○ **同じ版が別の端末・場所で開かれた**と分かる | ✕ 転送先が誰か(名乗らない限り) |
| スクリーンショットを撮られたか | △ 撮られても名前と日時が写り込む | ✕ 撮られたこと自体 |
| 印刷されたか | ✕ | ― |

転送を**防ぐ**機能(1回だけ開ける・端末固定・暗証番号)は、あえて入れていません。
受け手の手間が増えると「リンクを開くだけ」が崩れ、H2(現場が使うか)の検証が濁るためです。

## ファイル構成

```
配布ツール/
├ README.md              このファイル
├ mieie_haifu.py         本体(標準ライブラリのみ)
├ 起動する.command       ダブルクリックで起動
├ 公開する.command       ダブルクリックで外部公開(localhost.run)
├ config.json            管理キー(初回起動時に自動生成。他人に見せない)
└ data/
   ├ mieie.db            記録(SQLite)
   ├ files/              登録したPDFの保管
   └ exports/            日次ログ(刻印用)
```

`data/` と `config.json` は起動時に自動で作られます。
**Yasuo_Base の約束どおり、この一式は `~/Documents/` の下に置いたまま動かしてください。**

## 割り切り(最小版の限界)

- **Macが起きている間だけ動きます。**相手が開く時間帯はスリープさせないこと
- 公開アドレスは毎回変わる。常時運用に移すときは固定アドレスの環境へ(別途)
- PDFは `data/files/` に平文で置いています(外からはリンク経由でしか取れない)。暗号化保管は次の段階
- 閲覧の記録は「ページが開かれた」時点。PDF本体の取得までは追っていない
